Photo Booth

A full-stack web application that allows customers to book DSLR mirror photo booth services for events, while enabling admins to manage bookings, pricing, and schedules efficiently.

Key Features

• User-friendly booking form for event photo booth reservations
• Admin dashboard to view, approve, and manage bookings
• Dynamic price calculation based on event duration and services
• Secure backend APIs for booking and customer data
• Responsive UI built for desktop and mobile devices
• Role-based authentication for Admin and Users

Tech Stack

• Frontend: Angular 16, TypeScript, HTML5, CSS3, Bootstrap
• Backend: Java, Spring Boot, Spring MVC, Hibernate (JPA)
• Database: MySQL / PostgreSQL
• Tools: Git, Postman, VS Code, IntelliJ
• Deployment: Render / Railway

Pet Shop

A full-stack web application designed to manage pet shop operations, including pet listings, customer purchases, inventory management, and admin controls.

Key Features

• Admin dashboard to manage pets, categories, and inventory
• Add, update, delete pet details and prices
• Customer view to browse available pets and services
• Order and purchase management system
• Secure backend APIs with validation
• Responsive UI for all devices

Tech Stack

•Frontend: Angular 16, TypeScript, HTML5, CSS3, Bootstrap
•Backend: Java, Spring Boot, Spring MVC, Hibernate (JPA)
•Database: MySQL / PostgreSQL
•Tools: Git, Postman, IntelliJ, VS Code
•Deployment: Local Tomcat
